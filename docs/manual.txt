# Intro
Synth Cook Book is a preset cookbook for hardware synths without patch memory: Behringer Pro-1, CAT, TD-3-MO, TD-3, MODEL D and POLY D; Moog Mother-32, DFAM, Subharmonicon, Grandmother and Minimoog Model D; Arturia MicroBrute; Korg volca bass and volca keys. The Pro-1 cannot load or save sounds over MIDI, so a patch here is a recipe: a picture of the front panel with every knob and switch value, which you set by hand on the synth. The book runs in your web browser.

# Quick start
- Unzip the download and open SynthCookBook-RecipeBook.html in a browser (Firefox, Chrome, Edge, Safari). It draws the Pro-1 front panel at its real proportions: knobs, switches, patch jacks and wood cheeks.
- Pick a recipe from the Recipes shelf. Set your Pro-1 to match the panel on screen. Dashed rings and yellow question marks mark values that were read from a photo and are estimates.
- Drag a knob up or down, click a switch lever, drag the panel size slider or press Fit width. Open Recipe info, Patch cables and Patch sheet below the panel; Copy as text gives a plain recall sheet.
- Save keeps the recipe in the browser's own storage; Export file saves a .json file anywhere (a cloud folder works). Import loads files back. Export all saves every recipe of every synth in one file.
- The book also has panels for the other 13 synths (pick them in the Synth menu). The TD-3 panels include a 16 step piano roll for the pattern. The Pro-1, CAT, TD-3-MO and TD-3 panels are drawn from photos. The other ten are drawn from each manual's control list: sections and order follow the manual, not the exact hardware positions. Selectors with more than three positions are stepped dials. A small note under each of those panels says what the manual leaves unclear.
- Patch cable lists exist for the Behringer, Moog and Arturia synths that have a patchbay or mod matrix; the volca synths have none.
- SynthCookBook-PatchBook.html is the older, simpler page with the same patch format; it stays in the zip for people who shared patches with it.
- Drag a knob up or down to change its value. Double click a knob to put it back to the Init value.
- Type a name, author, category and notes, then press Export JSON to save your own patch as a file, or Copy JSON to paste it somewhere.
- Import loads a patch file you saved or received.
- The small scope is only a rough picture of the oscillator mix. It is not a model of the real synth.

# Patch files
- One patch is one .json text file (format in PATCH-FORMAT.md, included in the zip). Panel values use the printed scale of the Pro-1 (0 to 10, one decimal). Switches use the words printed on the panel.
- Share a patch by opening a "Submit a patch" issue on the GitHub repo and pasting the JSON, or by pull request. Only submit your own patches.
- The same page is also published online by the repo (GitHub Pages, folder docs) once the owner switches it on.

# Recommendations
- Start from Init and change one section at a time: oscillators, then mixer, then filter and envelopes.
- Note the modulation routes (wheel or direct) and any patch cables in the Notes field; they change the sound as much as the knobs.
- Keep your own patches in a folder next to the book, and back them up: they are plain text and small.

# Under the hood
- The recipe book is one HTML file. Recipes saved with Save live in the browser's own storage (localStorage); if the browser blocks storage, the page says so and recipes last only for the session. Export file, Import and Export all move them as .json files.
- Knob ranges in the tour tables were read from the page itself (each knob's minimum and maximum).
- A dashed ring on a knob means a value read from a photo (about plus or minus 1); a yellow question mark means low confidence; a dim control is still unset. Moving a control marks it as confirmed.
- The panel is drawn at the real front panel proportions and scales to the window (Fit width, 100%, or the slider).
- The page links Google Fonts for its typeface: it is the only network request in the file. Without a connection the browser shows a fallback font and everything else keeps working.
- The scope on the older Patch Book page is only a rough picture of the oscillator mix, not a model of the real synth.

# Install
- Nothing to install. Unzip anywhere and open the HTML file. To remove it, delete the folder.
- Windows, macOS and Linux all work; the page needs no internet connection.
